# Electricity Market Lab V1
https://electricity-market-lab-v1.vercel.app/
Synthetic four-zone lossless radial transport model. Piecewise-linear merit-order clearing with transfer constraints and load shedding at 3000 EUR/MWh. Prices are marginal estimates; degeneracy and zero-capacity interfaces can make dual prices nonunique. Generator margin uses bids as cost proxies. Battery is a manual offer/load, not energy-constrained. Hourly cases are independent. No real market data, AC power flow, unit commitment, reserve procurement or strategic agents yet.
